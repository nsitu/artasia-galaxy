# 2027 Opportunity: Placement Documentation in Google Drive

When a placement is created, automatically create its documentation folder structure in Google Drive. Establishing that structure at creation time would give each placement a single source of truth from the outset and encourage consistent organization across placements.

This could also enable a deeper import integration: the system could proactively sync placement images from Google Drive into Immich, rather than relying on users to import them manually. Any future implementation should define the canonical folder structure, placement-to-folder linkage, synchronization rules, duplicate handling, and how deletions or later edits are reconciled between Google Drive and Immich.
